# MCP Tool Rules

## Serena Tools for Code Operations

Prefer Serena MCP tools for navigating and editing code.

| Task | Tool |
| --- | --- |
| Find files | `mcp__serena__find_file` |
| List directory | `mcp__serena__list_dir` |
| Search source code | `mcp__serena__search_for_pattern` |
| Find function/class definitions | `mcp__serena__find_symbol` |
| Find all references to a symbol | `mcp__serena__find_referencing_symbols` |
| Explore file structure | `mcp__serena__get_symbols_overview` |
| Edit a symbol/function/class | `mcp__serena__replace_symbol_body`, `insert_after_symbol`, `insert_before_symbol` |
